摘要

强化学习已经成为描述现代 LLM 后训练（post-training）的主要语言之一：它把模型生成的行为转化为轨迹（trajectory）， 用反馈对这种行为进行评估，并更新模型，使更好的行为更可能出现。本教程从 LLM 的视角介绍强化学习， 以提示词（prompt）、词元（token）、奖励、验证器（verifier）、偏好数据和交互历史作为核心对象来展开。

全文的组织方式是一座渐进式的桥梁，而不是方法目录。它首先回顾把 LLM 看作策略（policy）所需的 LLM 与强化学习记号， 然后从一个具体的训练示例出发推导出 PPO 风格的 RLHF，解释为什么需要奖励、优势（advantage）、重要性采样（importance sampling） 和参考模型（reference model），之后才进入更强的奖励建模、高效优化、DPO、推理模型、智能体系统与多模态生成。

章节

  1. 引言 英文 PDF

    解释为什么 LLM 训练越来越需要针对完整行为的反馈，而不仅仅是词元级的示范数据。

  2. 预备知识：LLM 与强化学习 英文 PDF

    建立通用记号：LLM 侧的自回归生成、强化学习侧的马尔可夫决策过程（MDP）与轨迹，以及两者之间的对应关系。

  3. 理解 LLM 训练中的强化学习 英文 PDF

    从一个作业辅导助手的示例出发，逐步推导 PPO 风格的 RLHF 工作流：策略梯度、信用分配、优势、重要性采样、PPO 与奖励模型。

  4. 面向 LLM 的改进强化学习 英文 PDF

    重审基础工作流并追问实践中必须改进之处：奖励质量、奖励稀疏、奖励泛化、优势估计、训练效率，以及直接偏好优化（DPO）。

  5. 面向推理的强化学习 英文 PDF

    展示可验证推理如何把采样与搜索变成训练信号：Best-of-N、过程验证、蒙特卡洛树搜索（MCTS）、迭代式强化学习、大规模强化学习与同策略蒸馏。

  6. 智能体强化学习 英文 PDF

    把同一套反馈循环扩展到交互式智能体（agent）：规划、工具调用、环境、信用分配、记忆、技能与精炼如何共同塑造长轨迹。

  7. 多模态强化学习 英文 PDF

    超越纯文本策略：讨论面向理解任务的视觉奖励模型，以及面向扩散与流匹配生成的轨迹式强化学习。

  8. 结论与未来方向 英文 PDF

    回到全局视角，指出开放方向：面向预训练的强化学习、更廉价的强化学习、扩展极限预测，以及持续自我进化的模型。

  9. 附录：系统与数据集 英文 PDF

    汇总论文中提到的强化学习系统、偏好数据集、推理数据与智能体环境。
