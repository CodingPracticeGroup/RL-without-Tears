4 面向 LLM 的改进强化学习

上一节介绍了重要性采样、奖励基线等对强化学习的改进；但把它们直接用于训练 LLM 仍面临诸多挑战。 本节进一步深入，讨论用强化学习训练 LLM 的种种改进。

4.1 更高级的奖励模型

奖励模型是强化学习的基础组件，因为它定义了策略模型优化的目标。因此，奖励模型的训练质量直接影响 RLHF 阶段 LLM 优化的效果： 欠佳的奖励模型会把 LLM 引向次优，而优秀的奖励模型能确保 LLM 与期望的行为和目标有效对齐。这里我们介绍几种获得高级奖励模型的方法。 讨论会比较通用，因为奖励模型在机器人规划与控制等大量强化学习问题中都被广泛使用；这种通用性也让下文方法易于迁移到其他相关应用。

4.1.1 自动偏好数据生成

从人类偏好中学习是对 LLM 进行对齐的有效流行方法，但标注偏好数据代价高昂。依赖人类反馈不仅有可扩展性瓶颈，还可能引入偏差—— 人类反馈本质上是主观的。因此，基于 AI 的反馈方法为这些可扩展性与一致性问题提供了有前景的解法，绕开了人类标注的局限。

一种简单的方法是用 LLM 生成偏好数据。给定一组输入，先用 LLM 生成成对的输出，然后提示 LLM 对每一对之间的偏好进行标注……
